# TOEIC 词汇大师

基于 **间隔重复（SRS）+ 主动回忆（Active Recall）** 的纯前端托业词汇学习应用。
技术栈：Vue 3 (CDN) + Tailwind CSS (CDN)，无构建步骤，数据 100% 存于浏览器本地。

## 使用方法

直接双击打开 `index.html` 即可（或在本目录运行 `npx serve` 后访问 http://localhost:3000）。

## 功能一览

| 模块 | 说明 |
|---|---|
| 内置词库 | 30 个托业高频词，按 商务会议 / 市场营销 / 人力资源 / 财务金融 / 差旅办公 五大场景分类，含音标、中文释义、例句及翻译 |
| 联网查词 | 多源自动降级，**国内网络无需任何服务/代理**：① [Free Dictionary API](https://dictionaryapi.dev/)（音标/英文释义/例句，国际网络可达时生效，不通则一次超时后本会话熔断）→ ② [MyMemory](https://mymemory.translated.net/)（免鉴权带 CORS，词典级语料给出中文释义，大陆直连） |
| 单词发音 | 三级降级：词典 API 音频 → **有道 dictvoice 真人发音**（`<audio>` 不受 CORS 限制，国内可达）→ 浏览器内置 TTS（离线兜底）；闪卡正反面、测试结果、词库列表均可点 🔊，翻卡与出结果时默认自动朗读（可关闭） |
| 批量导入 | 词库管理页粘贴 .txt 内容（每行一个英文单词），自动清洗去重、串行限速查词并显示进度条 |
| 记忆算法 | 熟悉度 0–5 级，间隔曲线 `10分钟 → 1天 → 2天 → 4天 → 7天 → 30天`；反馈「认识」升级、「模糊」保持等级并按半间隔快速重练、「忘记」归零 10 分钟后重现 |
| 闪卡模式 | 3D 翻转卡片，正面单词/音标/星级，背面释义+例句（目标词高亮）；支持键盘 `空格` 翻转、`1/2/3` 反馈 |
| 拼写测试 | 逐格输入：一词一排格子、输入即显字母、退格可改、填满自动提交；💡提示按钮每题最多 2 次，依次揭示第 1、2 个字母（蓝格标记，用提示后即使拼对也按「模糊」计入记忆）；提交后逐格判分（绿=拼对，红=拼错带删除线，蓝=揭示）。保留编辑距离模糊匹配（短词容忍 1 字母误差、长词 2 个，大小写不敏感），答错按「忘记」处理 |
| 进度持久化 | 学习进度、词条编辑、删除记录全部存 localStorage（键 `toeic_srs_v2`），刷新/关闭浏览器不丢失 |

## 文件结构

```
toeic-words/
├── index.html      # 页面结构 + Vue 模板 + Tailwind
└── js/
    ├── data.js     # 内置词库与场景分类定义
    ├── srs.js      # 艾宾浩斯间隔算法 + 编辑距离模糊匹配
    ├── dict.js     # Free Dictionary API 封装（超时/降级/批量限速）
    └── app.js      # Vue 3 应用主逻辑
```

> 提示：在大陆网络下，导入词的中文释义与真人发音开箱可用；音标与例句需 `api.dictionaryapi.dev` 可达（挂代理时自动启用，重启页面即可补查）。个别词查不到时可在词库列表点 📖 重试，或点 ✏️ 手动补全。
